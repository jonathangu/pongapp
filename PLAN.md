# PongApp implementation contract

The approved product is a guest-first RackeTapp side game with:

- Duel (1v1), Arena (3–4 player free-for-all), Crosscourt (2v2), and AI practice.
- Private invite-code rooms with four active players and spectators.
- Two-player same-device play; online play supports up to four humans/AI.
- Dash, Bend, Guard, and Pulse signature skills.
- Grow, Overdrive, Multiball, Warp Gates, and Gravity Well power-ups.
- RackeTapp visual tokens, PixiJS effects, Web Audio, reduced motion, and
  accessible player patterns.
- Server-authoritative room physics and idempotently recorded match results.

Initial launch excludes ranked queues, public matchmaking, text chat,
pay-to-win progression, hosted accounts, RackeTapp backend work, and a
RackeTapp navigation link. The standalone game must prove stable on real
devices before integration is reconsidered.
