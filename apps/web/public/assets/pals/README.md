# Pal sprite set

Generated for PongApp on 2026-08-22 with OpenAI image generation, then
background-keyed and cropped into four transparent 512×512 PNGs.

- `bumper.png`: guard / Bumper
- `hook.png`: striker / Hook
- `captain.png`: Captain
- `hatchling.png`: Captain's Hatchling
- `pal-atlas.png`: transparent source atlas retained for future animation work

The sprite size is visual only. Authoritative collision radii remain in
`@pongapp/game-core`, so the new art does not change competitive power.
